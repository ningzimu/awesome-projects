# Awesome Projects

[English](README.md) | 简体中文

一个简洁、经过筛选的优秀开源项目、工具、应用与资源合集，不限制领域和类型。

[![Awesome](https://awesome.re/badge.svg)](https://github.com/sindresorhus/awesome) [![GitHub stars](https://img.shields.io/github/stars/ningzimu/awesome-projects?style=flat&logo=github&label=stars)](https://github.com/ningzimu/awesome-projects/stargazers) [![GitHub forks](https://img.shields.io/github/forks/ningzimu/awesome-projects?style=flat&logo=github&label=forks)](https://github.com/ningzimu/awesome-projects/forks)

这里用于收录不适合放进 [Awesome Skills](https://github.com/ningzimu/awesome-skills) 或 [Awesome AI PPT](https://github.com/ningzimu/awesome-ai-ppt) 的优秀项目。项目是否入选主要看实用性、完成度和长期价值，而不是类型或热度本身。

## 让 AI 帮你找项目

把下面这句话发给你的 AI：

> 安装这个 Skill：https://github.com/ningzimu/awesome-projects/tree/main/skills/awesome-projects

安装后，它会读取最新项目列表，回到原始仓库核验候选，并根据你的实际需求和限制推荐合适的项目。

## 收录范围

- 收录具有明确长期价值的公开项目、工具、应用、代码库、数据集与资源。
- 优先选择仍在维护、文档准确、用途清晰的项目。
- 链接必须指向原始来源，每个条目用一句简洁、准确的话说明价值。
- Agent Skills 放入 [Awesome Skills](https://github.com/ningzimu/awesome-skills)，AI 演示与 PPT 资源放入 [Awesome AI PPT](https://github.com/ningzimu/awesome-ai-ppt)。
- “公开可访问”和“具有明确开源许可证”是两件事，需要分开核验。

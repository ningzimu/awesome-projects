This list is the broad home for excellent projects that do not belong in [Awesome Skills](https://github.com/ningzimu/awesome-skills) or [Awesome AI PPT](https://github.com/ningzimu/awesome-ai-ppt). Entries are selected for usefulness, quality, and lasting value rather than category or popularity alone.

## Let your AI find projects for you

Send this to your AI:

> Install this skill: https://github.com/ningzimu/awesome-projects/tree/main/skills/awesome-projects

The skill checks the live list, verifies serious candidates against their original repositories, and recommends projects that fit your actual constraints.

## Scope

- Include useful public projects, tools, applications, libraries, datasets, and resources with clear long-term value.
- Prefer maintained projects with accurate documentation and a clear purpose.
- Link to the original source and describe each entry in one concise, factual sentence.
- Keep Agent Skills in [Awesome Skills](https://github.com/ningzimu/awesome-skills) and AI presentation resources in [Awesome AI PPT](https://github.com/ningzimu/awesome-ai-ppt).
- Treat public availability and an explicit open-source license as separate facts.
